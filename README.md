# BugHunter X

Authorized security research platform foundation for Android.

## v0.1
- Kotlin + Jetpack Compose Android app
- Dark Material 3 UI
- Explicit authorization gate
- HTTP/HTTPS scope validation
- Scope Firewall foundation
- Findings and severity models
- Evidence Vault / secret-protection foundations
- Submission snapshot foundation

## Safety boundary
Only assess assets for which you have explicit authorization. This project intentionally does not provide credential attacks, brute-force automation, exploit automation, or unrestricted third-party scanning.

## Requirements
- Android Studio
- JDK 17
- Android SDK 35

## Roadmap
1. Persistent programs and scope
2. Passive HTTP/TLS/header analysis
3. Findings, deduplication and risk scoring
4. Protected Evidence Vault
5. Exact Submission Preview and approval
6. Reports and exports
7. Backend synchronization and audit log
